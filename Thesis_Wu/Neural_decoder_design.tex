        \label{fig:GRU_cell}

\begin{multicols}{2}

\begin{align}
    h_t &= g^{GRU} \left(  h_{t-1}, \ x_t  \right)
\end{align}

\noindent and the four equations in the GRU cell:

\begin{align}
    % \label{eq:gru_cell}
    % \begin{split}
        r_t &=  \sigma (W_r h_{t-1} + U_r x_t + b_r) \label{eq:reset_gate} \\
        z_t &= \sigma (W_z h_{t-1} + U_z x_t + b_z) \label{eq:update_gate} \\
        \tilde{h_t} &= \phi(W (r_t \circ h_{t-1}) + U x_t + b) \label{eq:h_hat} \\
        h_t &= z_t \circ h_{t-1} + (1-z_t) \circ \tilde{h_t} \label{eq:h_out}
    % \end{split}
\end{align}

\noindent and the two activation functions:

\begin{align}
    \sigma (x) &= \frac{1}{1+e^{-x}} \label{eq:sigmoid} \\
    \phi (x) &= \frac{ e^{x}-e^{-x} }{ e^{x}+e^{-x} } \label{eq:tanh}
\end{align}

Where $r_t$ is the \textbf{Reset Gate} and $z_t$ is the \textbf{Update Gate}.
Notation $\circ$ means elementwise multiplication for two tensors of same shape.
Operator $\sigma$ is the sigmoid function (Equation \ref{eq:sigmoid}), which squashes the input value from ($-\infty$, $\infty$) to (0,1).
$\phi$ is the hyperbolic tangent (tanh) function (Equation \ref{eq:tanh}), squashing the input value from ($-\infty$, $\infty$) to (-1,1).
Two functions plotted in Figure \ref{fig:sigmoid_and_tanh}.
However, both of them have drawbacks of saturation problem, e.g., the derivative of input value outside the range [-4, +4] will be nearly 0 after activations, 
making its gradient vanish and slowing down learninig process.
The solution about this issue will be addressed in Section~\ref{sec:layer_norm}.
\end{multicols}

\begin{multicols}{2}
At each timestep, a single GRU cell can take in two tensors, one is the current input tensor $x_t$ and another is the previous hidden state $h_{t-1}$, which is the output from last timestep.
In the process of calculating each gate value (Equation \ref{eq:reset_gate}, \ref{eq:update_gate}) and $\tilde{h_t}$ (Equation \ref{eq:h_hat}),
hidden state from last timestep ($h_{t-1}$) will be multiplied by unique weights ($W_r$, $W_z$, $W$),
and so does the input tensor ($x_t$) will be multiplied by its own weights ($U_r$, $U_z$, $U$).
After the multiplication, 3 biases ($b_r$, $b_z$, $b$) will be added to the results before entering the activation functions

A hyperparameter named \textbf{hidden dimension} or \textbf{number of hidden units} specified the dimensions for all hidden states, which is a vector.
This hyperparameter also determine the number of each gates, i.e. with the setting of $u$ hidden units,
the shape of all hidden states should be $1 \times u$ and there will be $u$ reset gates, $u$ update gates in each cell.
Typically with the larger the hidden dimension, the more complex the model will be.
However, sophisticated models tend to overfit.

Figure \ref{fig:two_layer_GRU} demonstrated how hidden states are passed from one layer to another.
Where $n$ is the order of our input, representing how many the time bins to be fed into the model at a time for decoding the current kinematic states.
The input data at a time contains the firing rate at this moment $x_t$ and the past firing rate from $x_{t-n+1}$ to $x_{t-1}$.
The corresponding outputs of our model are the kinematic variables at time $t$.
\end{multicols}

Hidden state $h^{j}_{i}$ denotes the output tensor from the cell in timestep $i$ and layer $j$, and will be the input to the cell in timestep $i+1$ and layer $j+1$.
The size of $h^{j}_{i}$ should be $1 \times u$ since $u$ is a predefined parameter.
Ideally tensor $h^{2}_{t}$ should contain the information from the firing rate $x_{t-n+1}$ to $x_{t-1}$, thus by feeding it to some fully connect layers we can acquire the desired output.

\subsection{Layer normalization}
\label{sec:layer_normalization}
% https://towardsdatascience.com/understanding-dataset-shift-f2a5a262a766
\begin{multicols}{2}
With the novel normalization method proposed by \cite{ba2016layer}, \textit{layer normalization} is designed to overcome the setbacks of batch normalization, 
when it is implemented in RNNs.
Internal covariate shift is a problem caused by the variant distribution of the output of a previous layer,
which are used to be the input of its following layer.
It can be mitigated by fixing the mean and the variance of the summed inputs within each layer.
By the approach of normalization it can also provent the gradient vanishing problem from happening, which was brought up in Section~\ref{sec:RNN}.

Here is the computation of mean and variance from all the hidden units in the same layer:

\begin{align}
    \begin{split}
        \label{eq:normalization_term}
        \mu^l &= \frac{1}{H} \sum^{H}_{i=1} a^l_i \\
        \sigma^l &= \sqrt{ \frac{1}{H} \sum^H_{i=1} \left( a^l_i -\mu^l  \right)^2 }
    \end{split}
\end{align}

\noindent where $H$ denotes the number of hidden units in a layer, 
all the hidden units in a layer share the same normalization terms $\mu$ and $\sigma$.
Unlike batch normalization, 
layer normalization does not impose any constraint on the size of a mini-batch,
such that it cam be implemented to the model with batch size 1.

The original layer normalization methods is computed within a RNN cell.
In a standard RNN, 
the summed inputs in the recurrent layer are computed from the current input $x_t$ and previous vector of hidden states $h^{t-1}$, 
which are computed as $a^t = W_{hh} h^{t-1} + W_{xh} x^{t} $. 
Where $W_{hh}$ is the recurrent hidden to hidden weights and $W_{xh}$ are the input to hidden weights.
The layer normalizationed recurrent layer re-centers and re-scales its activations using the extra normalization terms similar to Equation \ref{eq:normalization_term}:

\begin{align}
    \begin{split}
        h^{t} &= f \left[ \frac{g}{\sigma^t} \odot \left( a^t- \mu^t \right) +b \right] \\
        \mu^t &= \frac{1}{H} \sum^{H}_{i=1} a^{t}_{i} \\
        \sigma^t &= \sqrt{ \frac{1}{H} \sum^{H}_{i=1} \left( a^t_i - \mu^t \right)^2 }
    \end{split}
\end{align}


\noindent where $\odot$ is the elementwise multiplication, 
and $b$, $g$ are defined as the bias and gain parameters of the same dimension as $h^t$.
$f$ is the activation function in the RNN cell, it could be a sigmoid or hyperbolic tangent function.

We define layer normalization as a function mapping $LN: \mathbb{R}^D \rightarrow \mathbb{R}^D$ with two set of adaptive parameters,
gains $\alpha$ and biases $\beta$:

\begin{align}
    \begin{split}
        LN(z; \ \alpha, \ \beta) &= \frac{(z-\mu)}{\sigma} \odot \alpha + \beta \\
        \mu &= \frac{1}{D} \sum^{D}_{i=1} z_i \\
        \sigma &= \sqrt{ \frac{1}{D} \sum^{D}_{i=1} \left( z_i- \mu \right)^{2} }
    \end{split}
\end{align}

When implementing it on GRU,

\begin{align}
    \begin{split}
        \begin{pmatrix}
            z_t \\
            r_t
        \end{pmatrix} &=  \sigma( W_h h_{t-1} ) + \sigma( W_x x_t ) \\
        \tilde{ h_t } &= \tanh( W x_t +  r_t \odot \left( U h_{t-1} \right) ) \\
        h_t &= \left( 1- z_t \right) h_{t-1} + z_t \tilde{h_t}
    \end{split}
\end{align}

\noindent layer normalization is applied as follows:

\begin{align}
    \begin{split}
        \begin{pmatrix}
            z_t \\
            r_t
        \end{pmatrix} &=   \sigma( LN( W_h h_{t-1} ; \ \alpha_1, \ \beta_1 ) ) + \sigma( LN(  W_x x_t ; \ \alpha_2 , \ \beta_2 ) ) \\
        \tilde{ h_t } &= \tanh(  LN( W x_t ; \ \alpha_3, \ \beta_3 ) +  r_t \odot LN( U h_{t-1} ; \ \alpha_4, \ \beta_4 ) ) \\
        h_t &= \left( 1- z_t \right) h_{t-1} + z_t \tilde{h_t}
    \end{split}
\end{align}

\noindent where $\alpha_i$ and $\beta_i$ are initialized as vector of zeros and ones, respectively.

The affect of the layer normalization is illustrated in Figure~\ref{fig:layer_norm_before_after},
whicih we simulate two extreme cases of hidden state distributions.
First one has a dense distribution but the mean is deviated from zero, making most of its values above $+4$, and will be mapped approximately to zero no matter in both activation.
The second case has the mean of zero, but its wild distribution makes only a portion of its elements have gradient other than zero, after activations.

\subsection{Attention Mechanism}

\begin{multicols}{2}
\cite{lin2017structured} proposed a concise but effective attention mechanism.
The output hidden states from the last layer of GRU will be the input of our attention mechanism.
The hidden states matrix,
\begin{align}
    \begin{split}
        H_{n \times 2u} &= (h_1, \ h_2, \cdots \ h_n) \qquad \text{bidirectional RNN} \\
        H_{n \times u} &= (h_1, \ h_2, \cdots \ h_n)  \qquad \text{one-way RNN}
    \end{split}
\end{align}
\noindent where $u$ is the number of hidden units.
The output of the attention mechanism, the annotation vector, is computed as
\begin{align}
    \label{eq:annotation_vector_calculation}
    \begin{split}
        \vec{a} &= softmax( \vec{w_{s2}} \ tanh( W_{s1} \ H^{T} ) )  \\
        \vec{m} &= \vec{a} H
    \end{split}
\end{align}
\noindent where $W_{s1}$ is a weight matrix with shape $(d_a \times 2u)$ or $(d_a \times u)$ depends on the RNN direction number,
and $\vec{w_{s2}}$ is a vector with size $(1 \times d_a)$.
$d_a$ is an arbitrary hyperparemeter.
The size of the annotation vector $\vec{a}$ is $(1 \times n)$, which is the length of each input sequence and in or case,
The number of past time bins used to decode the current kinematic variables.
The function $ softmax: \mathbb{R}^K \rightarrow \mathbb{R}^K$ is defined as
\begin{align}
    \begin{split}
    softmax(z)_i &= \frac{e^{z_i}}{ \sum^{K}_{j=1} e^{z_j} } \\ 
    \text{for} \ i &=1, \cdots , K \\ 
    \text{and} \ z&= \left( z_1, \cdots,z_K \right) \in \mathbb{R}^K
    \end{split}
\end{align}
\noindent such that the summation of the vector $\vec{a}$ is $1$.
The embedding vector $\vec{m}$ is the new feature of size $(1 \times u)$, and can be fed into the next layer.

% This explain fc in matrix form https://stackoverflow.com/questions/51608879/weights-matrix-final-fully-connected-layer

The vector representation may focues on only one specific part of the input sequence, 
and is expected to reflect an aspect in the sequence.
Multiple aspects can be found if we implement multiple hops of attention to the same sequence.
Another hyperparameter, $r$, is designed to determine how many different parts can be extracted from the sequence.
The representations from Eqation \ref{eq:annotation_vector_calculation} is now changed to the matrix form in Eqation \ref{eq:annotation_matrix_calculation},
\begin{align}
    \label{eq:annotation_matrix_calculation}
    \begin{split}
        A &= softmax( W_{s2} \ tanh( W_{s1} \ H^{T} ) )  \\
        M &= A H
    \end{split}
\end{align}
\noindent where the vector $\vec{w_{s2}}$ is extend into a $(r \times d_a)$ matrix, denoted as $W_{s2}$,
and the embedding vector $\vec{m}$ becomes a $(r \times 2u)$ or $(r \times u)$ matrix $M$, depending on the RNN direction number.

Eqation \ref{eq:annotation_matrix_calculation} is equivalent to a 2-layer MLP,
the first layer reduces the dimension from $u$ to $d_a$, or in bidirectional case, reduces $2u$ to $d_a$.
The second layer reduces the dimension from $d_a$ to $r$, as Figure~\ref{fig:multiply_attetion_vecotr_to_hidden_states} illustrated,

\subsection{Penalization Term}
\begin{multicols}{2}
The purpose of developing such loss function specifically for our attention mechanism is to avoid repetitive information.
The embedding matrix $M$ should contains $r$ different parts of aspects from the same sequence.
But without further constraints, the attention mechanism might always provide similar summation weights for all the $r$ hops.
\cite{lin2017structured} also proposed an approach to optimize the distribution of the annotations across sequence,
named the \textit{penalization term} and defined as follows,

\begin{align}
    \label{eq:penalization_term}
    P &= {\norm{ A A^T - I }_F}^2
\end{align}

\noindent where $A A^T$ is a square matrix of size $(r \times r)$, 
and $\norm{\bullet}_F$ denotes the Frobenius norm of a matrix, which is defined as
\begin{align}
    \label{eq:frobenius_norm}
    \norm{X}_F &= \sqrt{ \sum^m_{i=1} \sum^n_{j=1} {|x_{ij}|}_2 }
\end{align}

\noindent illustrated in Figure~\ref{fig:penalization_term}

\end{multicols}

\begin{figure}[H]
    \begin{center}
        \includegraphics[width=1\textwidth]{penalization_term.png}
        \captionsetup{width=0.5\textwidth}
        \caption{Penalization term}
        \fontsize{10}{12}
        \label{fig:penalization_term}
    \end{center}
\end{figure}

\begin{multicols}{2}
\noindent indicates that the summation of the squared value of every element in the matrix $A A^T - I$ should be closed to $0$.
The term $P$ itself is a kind of loss function, and the value, which is an error,
should be multipled by a coefficient and then propagate backwards to modify the weights in the our attention mechanism.

To explain this design, let's start by considering two different annotation vectors $ \vec{a^i} $ and $\vec{a^j} $.
Both vectors share the same size $(1 \times n)$.
Due to the fact that $softmax$ is implemented, the summation of every element of these vectors is $1$.
The values each vector can be consider as a probability distribution.

In an extreme case, there should have the no overlapping between the probability distribution of these two vectors, 
thus the dot products $ \vec{a^i} \cdot \vec{a^j} $ should be $0$, and can be expressed as
\begin{align}
    0 < a_{ij} &= \sum^{n}_{k=1} a^i_k a^j_k < 1
\end{align}
\noindent where $a_{ij}$ is a non-diagonal element in matrix $A A^T$, also should equal to $0$.
$ a^i_k $ and $ a^j_k $ are the $k$-th elements in vector $\vec{a^i}$ and ${\vec{a^j}}$, severally.
The diagonal elements, on the other hand,
will always be $1$ since they are the dot products of two identity vectors ($ \vec{a^i} \cdot \vec{a^i}$, i=1 $\sim$ r). 
That's why substracting an identity matrix from $A A^T$ is needed when calculating $P$.
The author of \cite{lin2017structured} claimed that in this way, 
each annotation vector $a^i$ is encouraged to focus on fewer parts of the sequence,
enabling each vector be focused on a single aspect. 

\end{multicols}

To define the coefficient of determination $R^2$ and the signal-to-noise ratio (SNR), 
two vectors are required which are the observed value $ \vec{y} = \left[ y_1, \cdots , y_n  \right]^{T} $ and predicted value $ \vec{f} = \left[ f_1, \cdots , f_n \right]^{T} $.
First we compute the mean of the observed data:
\begin{align}
    \bar{y} &= \frac{1}{n} \sum^{n}_{i=1} y_i
    \intertext{ then the total sum of squares, }
    SS_{tot} &= \sum^{n}_{i=1} \left( y_i - \bar{y} \right)^{2}
    \intertext{ the residual sum of squares, }
    SS_{res} &= \sum^{n}_{i=1} \left( y_i - f_i \right)^{2}
    \intertext{ with that the coefficient of determination will be }
    R^{2} &\equiv 1 - \frac{ SS_{res} }{ SS_{tot} } \label{eq:r_square}
    \intertext{ the SNR is defined by:}
    \text{SNR} &\equiv -10 \log_{10} (1 - R^{2})
\end{align}

\noindent and since the length of the testing data varied, weighted average is used to compute the mean performance across sessions,
with the weights equal to the testing data length.
\end{multicols}
